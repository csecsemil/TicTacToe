Welcome to Tic Tac Toe, an enhanced web-based puzzle game featuring multiple game modes, dynamic board sizes, and multiplayer support!



Game Modes
-2 Player (3x3 Mode): Traditional Tic Tac Toe played on a standard 3x3 grid. Players take turns placing X and O, aiming to align 3 symbols in a row, column, or diagonal.

-3 Player (5x5 Mode): An extended tactical version played on a 5x5 grid with three players (X, O, and Z). The goal is to get 3 matching symbols in a row to claim victory.



strHow to play
Select Mode: Click on the mode buttons at the top of the screen to switch between 2-player or 3-player mode.

Make a Move: Click on any empty cell on the game board to place your current symbol.

Winning & Draws: The game automatically detects winning combinations (highlighted with a green pulse animation) or triggers a draw when the board is full.

Reset / New Game: Click the Reset button or use the New game! pop-up modal to restart at any time.
